# config

The configuration model (defaults, override loading and in-place editing) and the single source of truth for where everything lives under the base directory: settings files, models, PID file, event log. See [configuration](../concepts/configuration.md).

Changing a default or adding a field here means updating the generated reference and the README field tables.
